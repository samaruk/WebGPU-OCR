00b Rectification

Checked: radial lens distortion is undone and the detected page quad is warped back to a rectangle; every later section works on that rectified image. Unchecked: both corrections are skipped and every section works on the original image as loaded.

01 Binarisation · Sauvola

Local mean / std window of the adaptive threshold T = m·(1 + k·(s/R − 1)). Runs on the GPU.
Connected components below this pixel count are speckle and are dropped before any analysis.

02 Borders · rules

Rules are traced on a separate Sauvola binary built with the lower k below (thin and faint rules survive), then interpreted as a full table grid, a vertical grid, a boxed header row, stacked row rules or section separators. Their pixels are painted out of the working image with the surrounding paper, so text lines and columns never see a rule, and the table region and column boundaries are handed to the column stage.
A horizontal rule at least this fraction of the page width (or a vertical one of the page height) counts as long: only long rules can form stacked row rules; the grid uses every rule that intersects another.
A long rule outside the table at least this wide is a section separator.
Rule tracing · solid rules
Rules are extracted by bridging gaps in each row / column, then a morphological opening keeps only locally-near-horizontal (or near-vertical) structures, then per-component centreline tracing gives a polyline.
A horizontal rule must span at least this fraction of the image width. Vertical rules use a much lower fixed fraction so short cell borders survive.
Gaps up to this many pixels between consecutive ink runs in the same row / column are bridged (text crossings). Set ≥ the widest glyph that typically crosses a rule.
Erosion + dilation radius. Larger rejects text more aggressively but tolerates less curvature.
Discards rules whose mean ink thickness exceeds this. Genuine rules are 1–3 px; text lines register as 6–15.
Fraction of the traced polyline that coincides with ink in the binary. Real rules score ≈ 1; joined shards score lower.
Rule tracing · dashed / dotted rules
Small components clustered into chains with uniform size and stride. Chains failing periodicity, size consistency or stride-to-size gates are rejected.
A dashed rule has stride ≫ dot size; tightly packed small text has stride ≈ character width.

03 Text lines · clean

Runs on the rules-erased image. Character components are filtered, chained into text lines, and only the ink of accepted lines is kept. Chaining (not dilation) is used so that skewed lines are followed and stacked lines never fuse; a pen tick or stroke that reaches two lines is detected as a bridge and can never join them.
Components shorter than this fraction of the reference glyph height are noise: dust, halftone dots, thin rules.
Taller components are cut at their ink valleys; whatever is still taller (logos, vertical rules, box borders, uncuttable merges) is removed. Raise it if a large-font heading disappears.
Width ÷ height above this is rule-shaped. Touching characters in bold or small fonts rarely exceed 6–8.
Two components on the same line are linked when the horizontal gap between them is at most this multiple of the taller one. Word spaces are ≈ 0.3–0.6; column gutters are usually 2+.
Linked components must overlap vertically by this fraction of the shorter one. Lower follows steeper skew; higher separates tightly stacked lines more strictly.
Chains with fewer components are rejected. At 1, a lone component is still accepted only if it looks like a glyph and sits inside the page.

04 Columns

Works on the full lines of section 03 in the de-skewed frame. Rows with enough pieces form the table band; a glyph coverage profile across the band exposes the gutters; the intervals between gutters are the columns and every glyph goes to the column under its centre.
A full line with at least this many pieces counts as a table row. Key / value rows like "Invoice Date : 16.05.2026" have 2 pieces, so 3 keeps them out of the band.
How many consecutive non-tabular rows (blank or wrapped cells) may sit inside the band without ending it.
An invoice has one item table. When a watermark, a pen line or a paper fold damages a few rows, the table shows up as two runs of tabular rows; a second run within this many rows of the main one is merged back in when its glyphs respect the same gutters. 0 disables merging.
A valley narrower than this cannot be a gutter. A gutter is either a clear run (coverage below the max below) or a deep valley — coverage at most 42 % of the lower neighbouring peak — which is how columns separated only by a word-space-sized gap that lines up in every row are found.
A clear gutter may be crossed by at most this fraction of the band rows (a long product name spilling into the next column).

05 Characters

Inside each accepted line, stacked parts of one symbol (i-dot and stem, the dots of a colon) are joined, and a component much wider than the line\u2019s typical character is cut at the low-ink valleys of its column profile.
Two components of the same line are one symbol when their x ranges overlap by this fraction of the narrower one.
A symbol wider than this multiple of the line\u2019s median character width is a merge and is cut. Keep it above 1.5 so m and w are not cut.
A cut column must carry at most this fraction of the component\u2019s mean ink per column.
Pieces narrower than this are merged back into their neighbour, and cuts are at least this far apart.

06 Recognition

Each full line is recognised on the clean binary in single-line mode and the engine\u2019s symbols are mapped onto the character boxes. The library and language data are downloaded from the jsDelivr CDN the first time and cached by the browser, so the first run needs a network connection.
Small text is upscaled (integer factor, up to 4×) so the reference glyph height reaches about this many pixels before recognition.
Adds a 2 px ring of contrast-normalised grayscale from the rules-erased image around every glyph, so the engine sees anti-aliased edges. Helps clean scans; on tight bold digits it can blur neighbours together, so it is off by default.
