Strata.

multi-scale horizontal erosion

Upload an image → Sauvola adaptive binarization → iterative 3×1 horizontal min-downsample: every 3 columns collapse to 1, and the group is feature only if all three are feature; if any is non-feature the output is non-feature and the contributing columns are marked back onto the original in that pass's colour. Repeats — width ÷3 each pass, a new colour each time — until the target width is reached. Marks live only on the original; each downstream stays a clean binary fed to the next pass.

Pipeline notes. Sauvola threshold per pixel: T = m·(1 + k·(s/R − 1)) over a window, via integral images. Each pass groups 3 adjacent columns of the current binary into 1 output column (incomplete edge groups count as non-feature). A pass-p output column maps to a block of 3p original columns on one row — that whole block is painted with the pass colour wherever the output is non-feature. Everything runs on the CPU; the per-pixel kernels port cleanly to WGSL compute if you want it on WebGPU.
