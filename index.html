CLAHE (Contrast Limited Adaptive Histogram Equalization) — divides the image into an 8×8 tile grid; each tile gets its own histogram, clipped at 2.5× the average bin height to prevent noise amplification. Excess is redistributed evenly before CDF normalisation. Tile LUTs are bilinearly interpolated to eliminate block boundaries. Implemented in 3 WGSL passes using workgroup atomic histograms and a Hillis–Steele parallel prefix sum for the CDF.

Guided Filter — self-guided (I = p = CLAHE output). Per-pixel local mean μ and variance σ² produce coefficients a = σ²/(σ²+ε) and b = μ(1−a). At edges (high σ²) a≈1 → output ≈ original; in flat regions (low σ²) a≈0 → output ≈ local mean. Preserves text strokes sharply while eliminating sensor noise.

Sauvola Thresholding — T(x,y) = μ · [1 + k·(σ/R − 1)] where μ and σ are computed in a 31×31 local window. Adapts the threshold pixel-by-pixel to handle uneven illumination, shadows, and ink bleed that defeat global Otsu.

Shader: detection.wgsl — sobelPass (3×3 Sobel Gx/Gy, magnitude clamped to [0,1]), probabilityMapPass (7×7 local edge-density with smoothstep, DBNet probability map analogue), dilatePass (5×5 morphological max-dilation to connect strokes). Bounding boxes computed CPU-side via 2-pass connected-component labelling with union-find. Letter Boundaries: second connected-component pass on the binarized image isolates each individual letter blob; each component is assigned a unique golden-angle HSL color with a 2-pixel bright boundary and a dimmed interior fill on a black background.

Shader: cnn.wgsl — convPass (3×3 same-padding convolution; filter weights uploaded via storage buffer per pass), reluPass (max(0, x) activation), maxPoolPass (2×2 stride-2 max pool; dispatched at workgroup_size(8,8)). 8 hand-crafted filters: Sobel-H, Sobel-V, Diag-NW, Diag-NE, Laplacian, Sharpen, Emboss, Smooth. Text Feature Image: 6 edge-filter responses (Sobel-H/V, Diagonals, Laplacian, Sharpen) composited pixel-by-pixel onto a black canvas at original input resolution — each pixel is colored by its dominant text filter (cyan/violet/green/amber/coral/white), with low-response pixels left black.
